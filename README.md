# TalantaLink 🌟

**Don't let talent go unseen.**

A platform where:
- 🌟 **Talented children & students** create athlete profiles and apply to trials — so their talent doesn't go to waste
- 🔭 **Scouts** search students by sport, position, age and county, and invite them directly (verified scouts only)
- 🏟️ **Everyone** finds their **nearest training facility** — courts, pitches, tracks and halls with prices and training times
- 📋 **Coaches & academies** post trials and scouting opportunities
- 📊 **My Journey** tracks applications, saved opportunities and scout connections (saved on-device)

## Run it
Open `index.html`, or:
```bash
python3 -m http.server 8080 --directory .
# http://localhost:8080
```

Single-file HTML/CSS/vanilla JS, mobile-first, no login. Demo data only.
See `DEVPOST_SUBMISSION.md` for pitch, demo script and judge Q&A.
